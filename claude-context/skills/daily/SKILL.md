# Daily — Morning Brief or Evening Reflection

1. Check what time it is relative to Soumil's schedule to determine: morning brief or evening reflection.
2. Read today's daily note at `Daily Notes/<today>.md`. If it doesn't exist, create it from `Templates/daily-note.md`.
3. Read yesterday's note. List anything that slipped.
4. Check Inbox/ for unprocessed captures — flag if any are older than 7 days.
5. Check any active Projects with `due:` within 7 days.

**If morning:**
- State the ONE big thing for today based on open projects and goals.
- List calendar items if known.
- Ask: what are you avoiding today?
- Update the morning brief section of today's note.

**If evening:**
- Ask 3 questions: what went well, what slipped, what tomorrow's ONE big thing is.
- Update the evening reflection section.
- Note any vocabulary or speech patterns worth flagging for the weekly review.

Keep it tight. Direct. No fluff.
