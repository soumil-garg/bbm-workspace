Soumil (2026-10-06) rejected the $0.15 test that would check whether run length predicts performance. His rule: keep "ran longer = did better", and also treat an ad concept as a winner for that brand when they keep duplicating it or reusing the same offer or headline.

**Why:** he considers these signals good enough for inspiration and does not want to spend time or money validating them.
**How to apply:** in competitor sweeps record both run length and copy count (collation_count / duplicates) per concept, count each picture once for shares, and label such concepts "likely winner, unproven". Caveat to keep stating: the agents found no study validating either signal, and in the 13-brand data copy count and run length were unrelated, so they are two separate signals.
