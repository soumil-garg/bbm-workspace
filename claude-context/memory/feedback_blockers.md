When facing any blocker, caveat, or limitation, do not just explain the problem. Immediately search the internet and come back with real, implementable alternatives.

**Why:** Sir explicitly said this after the Gemini API billing issue — where explaining the problem without finding the Cloudflare workaround would have been useless.

**How to apply:** The moment something fails or has a limitation (API quota, billing wall, broken package, access restriction), run web searches in parallel with diagnosing the issue. Present the solution, not the problem.
