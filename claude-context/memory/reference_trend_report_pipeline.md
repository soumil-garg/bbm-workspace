The Lotus trend report for Kyle (32 pages, chart-led PDF, built 4 Oct 2026) is generated by scripts in C:\cca\ga4\rpt. It sits on top of the GA4 helpers in [[reference_ga4_api]]. Output: C:\cca\ga4\rpt\Lotus Sculpture - Business Trend Report.pdf, copied to Desktop, Client Information, Lotus Sculpture, "Report for Kyle (Oct 2026)". Context and findings: [[client_lotus_sculpture]] and vault [[lotus-sculpture-trend-report-for-kyle-oct2026]].

Rebuild steps: `python pull.py` (fresh GA4 pulls into rpt\data; edit the date windows first), update the window constants in rdata.py (LAST, PRIOR) and the hard-coded GA4 totals in build_report.py (SESS_L, SESS_P, YTD_SESS), then `python fit.py` (re-renders every chart at the size of its page slot), then `python build_report.py` (writes report.html and prints the PDF through headless Chrome with --no-pdf-header-footer). Review pages by rendering the PDF with PyMuPDF (fitz) to PNG; check text with page.get_text().

**Why it is built this way:** a PDF made from HTML pages keeps layout control (cards, KPIs, sparklines) while matplotlib draws the charts; the NDA says nothing is published through AI tools, so it is NOT an Artifact. Every number in the page text is computed in build_report.py from the data, so rounding stays consistent (use the round-half-up helpers x1 and sgn, not Python format rounding: 4.25 must read 4.3x on every page).

**How to apply / gotchas:**
- Each chart has a slot in fit.py (pixel size on the page); charts render at about 1:1 at 96 dpi so fonts stay readable. If a chart looks tiny, its PNG is wider than the slot (often a long subtitle or tick labels): shorten text rather than letting fit.py shrink it.
- Do not use bash heredocs with backslashes or triple single quotes for Python that contains escape sequences: the tool layer turns `\\n` into real newlines. Write patch scripts with the Write tool and run them.
- Content rules for client reports: no BBM branding on Lotus; frame Google Ads, email campaign management and SEO as outside scope; label sensitivities as not forecasts; call GA4 "visits", "orders", "revenue"; GA4 session totals differ about 2 percent by slice, so say which total is used.
- Order-size statistics use orders with revenue above zero; channel groups are mapped in rdata.CH_MAP; product subjects and materials are grouped from item names in subject.py (approximate).
